# Expense Analysis using Pandas

A data analysis project built with Python and Pandas to analyze expense data and generate useful spending insights.

## Tools Used

* Python
* Pandas
* Jupyter Notebook
* Git & GitHub

## Analysis Performed

* Basic expense statistics
* Category-wise spending analysis
* Weekly spending analysis
* Weekly percentage change
* Spending-level classification
* Category average spending
* Difference from category average
* Data transformation and cleaning
* CSV data export

## Project Files

* `pandas_expense_project.ipynb` — Main analysis notebook
* `final_expense_analysis.csv` — Expense-level analysis
* `category_report.csv` — Category-wise summary
* `weekly_report.csv` — Weekly spending report

## Pandas Concepts Practiced

* `groupby()`
* `agg()`
* `transform()`
* `apply()`
* `resample()`
* `pct_change()`
* `shift()`
* Data filtering
* Data transformation
* CSV import/export

## What I Learned

This project helped me practice using Pandas to perform real-world data analysis, including grouping data, calculating statistics, working with dates and time series, creating derived columns, and exporting analysis results to CSV files.
