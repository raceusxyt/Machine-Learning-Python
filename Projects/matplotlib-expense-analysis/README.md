# Expense Analysis Dashboard with Matplotlib

## 📌 Overview

This project visualizes expense data using Python, Pandas, and Matplotlib. It combines six different visualizations into a single dashboard to help explore spending patterns, category-wise expenses, and individual transactions.

## 🎯 Objectives

- Compare total expenses across categories.
- Analyze daily spending trends.
- Understand the distribution of expense amounts.
- Compare individual expenses with category averages.
- Examine transaction counts by spending level.
- Visualize each category's share of total expenses.

## 📊 Visualizations

1. **Category-wise Expenses:** Bar chart comparing total expenses across categories.
2. **Daily Expense Trend:** Line plot showing changes in daily spending.
3. **Expense Amount Distribution:** Histogram showing the distribution of transaction amounts.
4. **Actual Expenses vs. Category Average:** Scatter plot comparing individual expenses with their category averages.
5. **Transactions by Spending Level:** Bar chart showing the number of transactions in each spending level.
6. **Expense Percentage by Category:** Donut chart showing each category's percentage of total expenses.

## ▶️ How to Run

1. Clone or download the repository.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib jupyter
   ```

3. Open the notebook:

   ```bash
   jupyter notebook expense_analysis_visualization.ipynb
   ```

4. Run the notebook cells in order.
