# Expense Visualization with Matplotlib

## 📌 Overview

This project uses Matplotlib to visualize expense data and explore spending patterns through individual charts.

## 🎯 Objectives

- Compare expenses across categories.
- Observe daily expense trends.
- Understand the distribution of expense amounts.
- Explore relationships between transaction numbers and expense amounts.

## 📊 Visualizations

- **Bar chart:** Compares expenses across categories.
- **Line plot:** Displays daily expense trends.
- **Histogram:** Shows the distribution of expense amounts.
- **Scatter plot:** Explores the relationship between transaction numbers and expense amounts.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## ▶️ How to Run

1. Clone or download the repository.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib jupyter
   ```

3. Open `expense_visualization.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.

## 📈 Key Learning Outcomes

- Creating bar charts, line plots, histograms, and scatter plots.
- Customizing chart titles, labels, colors, and grids.
- Visualizing data using Pandas and Matplotlib.
