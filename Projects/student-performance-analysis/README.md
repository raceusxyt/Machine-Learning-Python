# Student Performance Analysis with NumPy

## 📌 Overview

This project uses NumPy to analyze student marks and explore academic performance through numerical operations and array manipulation.

## 🎯 Objectives

- Calculate student averages and subject-wise performance.
- Compare student marks and rankings.
- Identify performance categories.
- Practice efficient numerical analysis using NumPy.

## 🛠️ Technologies Used

- Python
- NumPy
- Jupyter Notebook

## 📚 Key Concepts

- NumPy array creation and manipulation
- Indexing and slicing
- Aggregations and statistical operations
- Sorting and ranking
- Boolean indexing and numerical analysis

## ▶️ How to Run

1. Clone or download the repository.
2. Install NumPy and Jupyter Notebook:

   ```bash
   pip install numpy jupyter
   ```

3. Open the project's notebook in Jupyter Notebook.
4. Run the cells in order.
