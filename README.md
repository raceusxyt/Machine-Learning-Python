## 🚀 Projects

### 1. Expense Analysis with Pandas
A data analysis project using Pandas to clean, analyze, and summarize expense data.

**Key concepts:** data cleaning, grouping, aggregation, date/time analysis, expense summaries, and exporting analysis results.

### 2. Student Performance Analysis with NumPy
A NumPy-based project analyzing student marks, averages, rankings, subject performance, and performance categories.

**Key concepts:** array operations, aggregations, sorting, indexing, and numerical analysis.

### 3. Expense Visualization with Matplotlib
A visualization project that explores expense data through individual charts.

**Visualizations:**
- Category-wise bar chart
- Daily expense line plot
- Expense amount histogram
- Scatter plot comparing transaction numbers and expense amounts

**Technologies:** Python, Pandas, Matplotlib, and Jupyter Notebook.

### 4. Expense Analysis Dashboard with Matplotlib
A dashboard project that combines six visualizations into a single 3 × 2 layout using expense analysis data.

**Visualizations:**
- **Category-wise bar chart:** compares total expenses across categories.
- **Daily line plot:** shows how total expenses change over time.
- **Histogram:** displays the distribution of expense amounts.
- **Scatter plot:** compares individual expenses with their category averages, with a reference line.
- **Spending-level bar chart:** counts transactions by spending level.
- **Donut chart:** displays each category's percentage of total expenses.

**Technologies:** Python, Pandas, Matplotlib, and Jupyter Notebook.
